# juniper-prior-auth

Juniper Health Plan prior authorization agent (healthcare, tier 1, EU high-risk, not a medical device). Fictional.

| File | What it does |
|---|---|
| `model-card.yaml` | Pillar 1: model card (schema `schemas/model-card.schema.json`) |
| `data-sheet.yaml` | Pillar 2: data sheet |
| `risk-cards.yaml` | Pillar 3: risk cards with controls and owners |
| `scenarios.yaml` | Pillar 4: scenarios with thresholds |
| `approvals.yaml` | Lifecycle stage and sign-offs bound to the pillar digest |
